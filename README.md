# 🚀 About Me

I'm a Data Science undergraduate at UNSAM, passionate about applying data to solve real-world problems and building scalable systems that transform raw data into valuable insights.

🧪 Currently, I'm deepening my knowledge in Python, SQL, R, data visualization, and machine learning, while working on projects that integrate backend APIs, ETL pipelines, and data analytics with predictive modeling.

My experience in backend and web development — using technologies like FastAPI, Node.js, Express, MongoDB, PostgreSQL, and React — has given me a solid foundation in software engineering and a practical mindset for solving technical challenges.

I'm looking for opportunities where I can apply my backend and data skills to develop impactful tools, automate processes, and support strategic decision-making.
